# 🎓 Student Performance Prediction

## 📌 Project Overview

This project is a Machine Learning-based system that predicts student academic performance based on various behavioral and academic factors. It helps identify students who may need additional support by analyzing patterns in their data.

---

## ⚙️ Tech Stack

- Python 🐍
- Pandas
- NumPy
- Scikit-learn
- Matplotlib / Seaborn
- Jupyter Notebook

---

## 📊 Problem Statement

Educational institutions often need to identify students who may underperform. This project uses machine learning to predict student performance so early interventions can be made.

---

## 📁 Dataset Features

Typical features used in the dataset include:

- Study hours
- Attendance
- Previous exam scores
- Sleep hours
- Motivation level
- Family background factors
- Internet access
- Extracurricular activities

---

## 🧠 Machine Learning Models Used

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- Support Vector Regression (SVR)
- Gradient Boosting

---

## 📈 Model Evaluation Metrics

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score

---

## 🔄 Workflow

1. Data loading
2. Data preprocessing
3. Feature encoding
4. Model training
5. Model evaluation
6. Best model selection
7. Prediction generation

---

## 🚀 How to Run This Project

### 1. Clone Repository

```bash
git clone https://github.com/MahnoorNaseer/Student-Performance-Prediction.git
cd Student-Performance-Prediction
```

### 2. Create Virtual Environment

```bash
python -m venv venv
venv\Scripts\activate   # Windows
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run Jupyter Notebook

```bash
jupyter notebook
```
